# ربات اخبار گیم فارسی برای تلگرام 🎮 (نسخه‌ی خودکار با Gemini)

این ربات کاملاً خودکار عمل می‌کنه:

- از چند سایت معتبر گیمینگ (IGN، GameSpot، Eurogamer، PC Gamer) جدیدترین خبرها رو می‌گیره — اخبار انیمه دیگه پیگیری نمی‌شه
- خبر رو می‌ده به **Gemini** تا هم تشخیص بده ارزش انتشار داره یا نه (خبرهای کم‌ارزش مثل تخفیف/لیست/ریویو رد می‌شن)، هم به فارسیِ روان، **جذاب** و همراه با ایموجی‌های کیبورد بازنویسیش کنه (نه ترجمه‌ی خشک)
- عکس خبر رو پیدا می‌کنه
- یک **استیکر گیمینگ تصادفی** + عکس + متن جذاب رو مستقیم به **کانال شما** می‌فرسته

دیگه نیازی به گروه پیش‌نویس یا دستور `/post` نیست — همه‌چیز خودکاره.

---

## مرحله ۱: ساخت ربات تلگرام

1. تو تلگرام برید سراغ [@BotFather](https://t.me/BotFather)
2. دستور `/newbot` رو بزنید و اسم/یوزرنیم ربات رو انتخاب کنید
3. توکن ربات رو نگه دارید (چیزی مثل `123456789:AAExampleToken...`)

## مرحله ۲: آماده‌سازی کانال

1. کانالی که می‌خواید خبرها توش منتشر بشه رو بسازید (یا از قبلی استفاده کنید)
2. ربات رو به‌عنوان **ادمین کانال** اضافه کنید (با دسترسی ارسال پیام و عکس)
3. یوزرنیم (`@yourchannel`) یا آیدی عددی کانال رو یادداشت کنید

## مرحله ۳: گرفتن کلید Gemini (رایگان)

1. برید به [Google AI Studio](https://aistudio.google.com/apikey) و یک API Key رایگان بسازید
2. این کلید محدودیت روزانه‌ی رایگان داره (برای مدل Flash معمولاً هزار-چند هزار درخواست در روز) که برای این ربات کاملاً کافیه

## مرحله ۴: انتخاب پک استیکر (اختیاری ولی توصیه‌شده)

1. تو تلگرام دنبال چند پک استیکر گیمینگ که دوست دارید بگردید (سرچ کنید مثلاً «gaming stickers»، «game sticker pack»)
2. روی یکی از استیکرهای پک بزنید و لینکش رو باز کنید؛ لینک به این شکله:
   `https://t.me/addstickers/NAME_PACK`
   بخش `NAME_PACK` همون چیزیه که لازم دارید
3. می‌تونید چندتا پک معرفی کنید تا ربات هر بار تصادفی از بینشون انتخاب کنه

## مرحله ۵: نصب پیش‌نیازها

```
pip install -r requirements.txt
```

## مرحله ۶: تنظیمات

```
export BOT_TOKEN="توکن ربات شما"
export CHANNEL_ID="@yourchannel"                    # یا آیدی عددی کانال
export GEMINI_API_KEY="کلید Gemini شما"
export STICKER_PACK_NAMES="Pack1,Pack2,Pack3"       # اختیاری
export CHECK_INTERVAL_MINUTES="15"                  # اختیاری، پیش‌فرض ۱۵
export MAX_ITEMS_PER_RUN="5"                        # اختیاری، پیش‌فرض ۵
export DRY_RUN="0"                                  # با ۱، فقط تست می‌کنه و نمی‌فرسته
```

## مرحله ۷: اجرا

```
python news_bot.py
```

اول یه بار با `DRY_RUN=1` اجراش کنید تا مطمئن بشید خروجی‌ها خوب و جذاب هستن، بعد
`DRY_RUN=0` کنید تا واقعاً به کانال بفرسته.

---

## نکات مهم

- **اجرای ۲۴ ساعته**: برای اجرای همیشگی، رو یه VPS یا Railway دیپلویش کنید.
- **کنترل مصرف رایگان Gemini**: با `MAX_ITEMS_PER_RUN` و `CHECK_INTERVAL_MINUTES` می‌تونید تعداد درخواست‌ها به Gemini رو کنترل کنید تا از سقف رایگان روزانه رد نشید.
- **جلوگیری از تکرار**: لینک خبرهای بررسی‌شده (چه منتشر بشه چه رد بشه) تو `sent_news.json` ذخیره می‌شه.
- **کیفیت فیلتر خبر**: تشخیص «ارزش انتشار» کاملاً به عهده‌ی Gemini هست؛ اگه دیدید بیش‌ازحد سخت‌گیر یا بیش‌ازحد آسون‌گیره، می‌تونید پرامپت داخل `news_bot.py` (متغیر `GEMINI_PROMPT`) رو تنظیم کنید.
- **مدل Gemini**: پیش‌فرض `gemini-2.0-flash` هست چون رایگان و سریعه؛ با `GEMINI_MODEL` می‌تونید عوضش کنید.

## عیب‌یابی

| مشکل | راه‌حل احتمالی |
|---|---|
| خبری به کانال نمیاد | مطمئن شوید `DRY_RUN` روی `0` هست و لاگ کنسول رو چک کنید |
| خطای مجوز از تلگرام | مطمئن شوید ربات ادمین کانال هست و اجازه‌ی ارسال عکس داره |
| خطای Gemini (quota/429) | سقف رایگان روزانه پر شده؛ `MAX_ITEMS_PER_RUN` یا تعداد اجرا در روز رو کم کنید |
| استیکر نمیاد | اسم پک استیکر رو دوباره چک کنید (باید دقیقاً همون بخش بعد از `addstickers/` باشه) |
| عکس خبر نمیاد | بعضی فیدها عکس ندارن و og:image صفحه هم پیدا نشده؛ ربات به‌صورت خودکار فقط متن می‌فرسته |
