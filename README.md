# ربات اخبار گیم فارسی برای تلگرام 🎮

این ربات به‌صورت خودکار:
- جدیدترین اخبار گیمینگ رو از چند سایت معتبر (IGN، GameSpot، Eurogamer، PC Gamer) می‌گیره
- عنوان و خلاصه‌ی خبر رو با گوگل ترنسلیت به فارسی برمی‌گردونه
- خبر رو همراه با عکس (اگه موجود باشه) به کانال تلگرام شما می‌فرسته
- جلوی ارسال تکراری خبرها رو می‌گیره

---

## مرحله ۱: ساخت ربات تلگرام

1. تو تلگرام برید سراغ [@BotFather](https://t.me/BotFather)
2. دستور `/newbot` رو بزنید و طبق مراحل، اسم و یوزرنیم ربات رو انتخاب کنید
3. یک **توکن** بهتون می‌ده، مثل:
   `123456789:AAExampleTokenXXXXXXXXXXXXXXXXXXXXX`
   این توکن رو نگه دارید.

## مرحله ۲: آماده‌سازی کانال

1. یک کانال تلگرام بسازید (یا از کانال موجودتون استفاده کنید)
2. ربات ساخته‌شده در مرحله قبل رو به‌عنوان **ادمین کانال** اضافه کنید (حتماً دسترسی "ارسال پیام" رو بهش بدید)
3. اگه کانال **پابلیک** هست، یوزرنیمش رو یادداشت کنید (مثلاً `@mygamenews`)
4. اگه کانال **پرایوت** هست، باید آیدی عددی کانال رو پیدا کنید (معمولاً چیزی شبیه `-1001234567890`). ساده‌ترین راه: یک پیام تو کانال بفرستید، بعد اون پیام رو فوروارد کنید به ربات [@JsonDumpBot](https://t.me/JsonDumpBot) یا مشابه، و مقدار `chat.id` رو از خروجی بردارید.

## مرحله ۳: نصب پیش‌نیازها

```bash
pip install -r requirements.txt
```

## مرحله ۴: وارد کردن تنظیمات

فایل `news_bot.py` رو باز کنید و این دو خط رو با اطلاعات خودتون پر کنید:

```python
BOT_TOKEN = "توکن ربات شما"
CHANNEL_ID = "@yourchannel"   # یا آیدی عددی کانال پرایوت
```

یا به‌جای ویرایش فایل، می‌تونید این متغیرهای محیطی رو تنظیم کنید:

```bash
export BOT_TOKEN="توکن ربات شما"
export CHANNEL_ID="@yourchannel"
```

## مرحله ۵: اجرای ربات

```bash
python news_bot.py
```

ربات هر ۱۰ دقیقه یک‌بار (قابل تنظیم با `CHECK_INTERVAL_SECONDS`) فیدهای خبری رو چک می‌کنه و خبرهای جدید رو می‌فرسته. برای توقف، `Ctrl+C` بزنید.

---

## نکات مهم

- **اجرای ۲۴ ساعته**: اگه می‌خواید ربات همیشه روشن باشه، باید روی یه سرور (VPS) یا سرویسی مثل Railway، Render یا PythonAnywhere اجراش کنید؛ چون اگه سیستم خودتون خاموش بشه، ربات هم متوقف می‌شه.
- **افزودن/حذف منابع خبری**: لیست `RSS_FEEDS` رو داخل کد می‌تونید تغییر بدید و فید سایت‌های دیگه رو هم اضافه کنید.
- **کیفیت ترجمه**: از کتابخانه‌ی رایگان `deep-translator` (که از موتور گوگل ترنسلیت استفاده می‌کنه) استفاده شده. ترجمه معمولاً قابل‌فهمه ولی ماشینیه، نه ویرایش انسانی.
- **جلوگیری از تکرار**: لینک خبرهای ارسال‌شده تو فایل `sent_news.json` (کنار اسکریپت) ذخیره می‌شه. اگه بخواید ربات از صفر شروع کنه، این فایل رو پاک کنید.
- **محدودیت طول کپشن تلگرام**: تلگرام برای کپشن عکس حداکثر ۱۰۲۴ کاراکتر قبول می‌کنه؛ کد به‌صورت خودکار خلاصه رو کوتاه می‌کنه اگه لازم باشه.

## عیب‌یابی

| مشکل | راه‌حل احتمالی |
|---|---|
| پیام "ارسال ناموفق" می‌بینید | مطمئن شوید ربات ادمین کانال هست و CHANNEL_ID درست وارد شده |
| عکس‌ها ارسال نمی‌شن | بعضی فیدها عکس ندارن؛ در این حالت ربات به‌صورت خودکار فقط متن می‌فرسته |
| خطای مربوط به ترجمه | معمولاً موقتیه (محدودیت نرخ گوگل)؛ ربات خودش دوباره تلاش می‌کنه در چرخه بعدی |
