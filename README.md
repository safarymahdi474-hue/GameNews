# ربات اخبار گیم فارسی برای تلگرام 🎮

این ربات به‌صورت خودکار:
- جدیدترین اخبار گیمینگ رو از چند سایت معتبر (IGN، GameSpot، Eurogamer، PC Gamer، Anime News Network، Otaku Mode) می‌گیره
- با هوش مصنوعی (Gemini رایگان یا Claude) خبرهای کم‌ارزش (تخفیف، لیست، ریویو و...) رو فیلتر می‌کنه
- بقیه رو به فارسی روان ترجمه می‌کنه و همراه با عکس به یه **گروه پیش‌نویس** می‌فرسته

سپس شما تو اون گروه:
- رو خبری که می‌پسندید **ریپلای** می‌کنید و دستور `/post` رو می‌زنید
- ربات خط «منبع خبر» رو حذف می‌کنه و به‌جاش یه خط نقل‌قول‌شده با آیدی کانال اضافه می‌کنه، بعد خبر + عکس رو به **کانال نهایی** می‌فرسته

---

## مرحله ۱: ساخت ربات تلگرام

1. تو تلگرام برید سراغ [@BotFather](https://t.me/BotFather)
2. دستور `/newbot` رو بزنید و طبق مراحل، اسم و یوزرنیم ربات رو انتخاب کنید
3. یک **توکن** بهتون می‌ده، مثل:
   `123456789:AAExampleTokenXXXXXXXXXXXXXXXXXXXXX`
   این توکن رو نگه دارید.

## مرحله ۲: آماده‌سازی کانال نهایی

1. کانالی که می‌خواید خبرهای تاییدشده توش منتشر بشه رو بسازید (یا از قبلی استفاده کنید)
2. ربات رو به‌عنوان **ادمین کانال** اضافه کنید (با دسترسی ارسال پیام)
3. یوزرنیم یا آیدی عددی کانال رو یادداشت کنید

## مرحله ۳: آماده‌سازی گروه پیش‌نویس

1. یک گروه جدید بسازید (می‌تونه خصوصی باشه، فقط خودتون و ربات توش باشید)
2. ربات رو به گروه اضافه کنید (نیازی نیست ادمین باشه)
3. برای پیدا کردن آیدی عددی گروه: یه پیام تو گروه بفرستید، اون رو فوروارد کنید به [@JsonDumpBot](https://t.me/JsonDumpBot) یا مشابه و مقدار `chat.id` رو بردارید (چیزی شبیه `-1001234567890`)

## مرحله ۴: پیدا کردن آیدی عددی خودتون (برای امنیت دستور /post)

به [@userinfobot](https://t.me/userinfobot) پیام بدید تا آیدی عددیتون رو بگه. این آیدی رو تو تنظیمات `ALLOWED_USER_IDS` می‌ذارید تا فقط شما بتونید از `/post` استفاده کنید.

## مرحله ۵: نصب پیش‌نیازها

```bash
pip install -r requirements.txt
```

## مرحله ۶: تنظیمات

فایل `news_bot.py` رو باز کنید یا این متغیرهای محیطی رو ست کنید:

```bash
export BOT_TOKEN="توکن ربات شما"
export CHANNEL_ID="@yourchannel"              # کانال نهایی
export DRAFT_GROUP_ID="-1001234567890"        # گروه پیش‌نویس
export ALLOWED_USER_IDS="123456789"           # آیدی عددی شما (با کاما جدا برای چند نفر)
export GEMINI_API_KEY="..."                   # اختیاری ولی توصیه‌شده (رایگان)
```

## مرحله ۷: اجرا

```bash
python news_bot.py
```

## نحوه‌ی استفاده روزانه

1. ربات خبرهای فیلترشده و ترجمه‌شده رو خودکار تو گروه پیش‌نویس می‌فرسته
2. شما اخباری که می‌پسندید رو تو همون گروه **ریپلای** می‌کنید و می‌نویسید: `/post`
3. ربات همون خبر (با عکسش) رو با آیدی کانال به‌جای لینک منبع، به کانال نهایی می‌فرسته

---

## نکات مهم

- **اجرای ۲۴ ساعته**: برای اجرای همیشگی، رو یه VPS یا Railway دیپلویش کنید.
- **امنیت دستور /post**: حتماً `ALLOWED_USER_IDS` رو ست کنید، وگرنه هرکسی تو گروه پیش‌نویس می‌تونه به کانال پست بفرسته.
- **محدودیت تلگرام**: دستور `/post` فقط تو چت‌های خصوصی و گروه‌ها کار می‌کنه (نه داخل خود کانال)، چون تلگرام هویت کاربر واقعی رو تو پست‌های کانال به ربات نمی‌ده.
- **فرمت خبر بعد از /post**: بولد بودن عنوان خبر اصلی حفظ نمی‌شه (چون تلگرام فرمت رو جدا از متن نگه می‌داره)، ولی محتوا و عکس کامل منتقل می‌شه.
- **کیفیت ترجمه**: اگه `GEMINI_API_KEY` رو ست کنید، ترجمه و فیلتر اهمیت خبر با هوش مصنوعی و رایگان انجام می‌شه؛ وگرنه فیلتر کلیدواژه‌ای + گوگل ترنسلیت جایگزین می‌شه.
- **جلوگیری از تکرار**: لینک خبرهای ارسال‌شده تو فایل `sent_news.json` ذخیره می‌شه.

## عیب‌یابی

| مشکل | راه‌حل احتمالی |
|---|---|
| `/post` جواب نمی‌ده | مطمئن شوید دقیقاً رو پیام خبر ریپلای کردید و آیدی عددیتون تو `ALLOWED_USER_IDS` هست |
| پیام "ارسال ناموفق" می‌بینید | مطمئن شوید ربات ادمین کانال هست و `CHANNEL_ID` درست وارد شده |
| خبرها تو گروه نمیان | مطمئن شوید ربات عضو گروهه و `DRAFT_GROUP_ID` درسته (باید با `-` شروع بشه) |
| عکس‌ها ارسال نمی‌شن | بعضی فیدها عکس ندارن؛ در این حالت ربات به‌صورت خودکار فقط متن می‌فرسته |
